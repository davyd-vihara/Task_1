## 🎭 Использование моков

Моки используются в **5 тестах** для изоляции и проверки взаимодействия:

| Класс | Тест | Что мокируется |
|-------|------|----------------|
| **Burger** | `test_get_price` | Bun, Ingredient |
| **Burger** | `test_get_receipt_with_mocks` | Bun, Ingredient |
| **Database** | `test_database_initialization_with_mocks` | Bun, Ingredient |
| **Database** | `test_bun_creation_on_init` | Bun |
| **Database** | `test_ingredient_creation_on_init` | Ingredient |

**Зачем моки?**
- Изоляция тестов от зависимостей
- Контроль поведения объектов
- Проверка взаимодействия между компонентами

**Пример использования:**
```python
# Создаем мок для булочки
mock_bun = Mock(spec=Bun)
mock_bun.get_price.return_value = 100
burger.bun = mock_bun

# Проверяем вызов метода
mock_bun.get_price.assert_called_once()
```

## 📊 Использование параметризации

Параметризация используется в **13 тестах** для покрытия множества сценариев:

| Класс | Количество параметризованных тестов | Примеры |
|-------|-------------------------------------|---------|
| **Bun** | 3 теста | 5 наборов для инициализации, 6 для get_name, 6 для get_price |
| **Ingredient** | 4 теста | 6 наборов для инициализации |
| **Burger** | 4 теста | 4 сценария расчета цены |
| **Database** | 2 теста | 9 наборов данных |

**Особенности параметризации:**
- **Разные классы эквивалентности:** Латиница, кириллица, числа, спецсимволы, граничные значения
- **Изоляция параметров:** При тестировании одного параметра остальные фиксированы
- **Граничные значения:** Минимальные, максимальные, пустые строки, нулевые значения

**Зачем параметризация?**
- Покрытие большего количества сценариев одним тестом
- Меньше дублирования кода
- Легче добавлять новые тестовые случаи
- Покрытие разных классов эквивалентности

**Пример использования с изоляцией:**
```python
@pytest.mark.parametrize("name", [
    "black bun",  # Латиница
    "Булочка",    # Кириллица
    "bun123",     # Латиница с числами
    "bun!@#",     # Латиница со спецсимволами
    "",           # Пустая строка (граничное значение)
    "a",          # Минимальная длина (граничное значение)
])
def test_get_name(self, name):
    price = 100  # Фиксированная цена для изоляции теста
    bun = Bun(name, price)
    assert bun.get_name() == name
```
